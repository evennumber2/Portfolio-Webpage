# Portfolio Webpage — Ponduru Sivaprasad

An immersive cosmic-themed portfolio with 3D interactive background, glassmorphism design, and smooth animations. Built with Three.js and vanilla JS.

## ✨ Features

- **3D Interactive Background** — Three.js scene with particle starfield, rotating geometric shapes, and mouse-reactive parallax
- **Glassmorphism Design** — Frosted glass cards with animated gradient borders and shimmer effects
- **Custom Cursor** — With smooth follower and hover state transitions
- **Typing Effect** — Dynamic role text cycling through multiple titles
- **Animated Skill Rings** — SVG radial progress bars that animate on scroll
- **3D Tilt Cards** — Project cards with perspective transform and mouse-driven glow
- **Scroll Animations** — Section reveals with staggered fade-up effects
- **Fully Responsive** — Adapts seamlessly from desktop to mobile
- **Zero Backend** — 100% static, free to host on Netlify
